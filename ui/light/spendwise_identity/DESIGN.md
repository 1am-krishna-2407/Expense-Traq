## Brand & Style

The design system establishes a high-clarity, institutional-grade fintech aesthetic optimized for financial surveillance, budget control, and real-time expense reconciliation. It prioritizes analytical precision, trust, and zero-distraction data presentation. 

### Brand Personality & Emotional Core
- **Authoritative & Trustworthy:** Anchored by balanced royal blue tones, conveying the structural stability of an established banking platform paired with modern SaaS velocity.
- **Analytical & Precise:** Dense numeric data and currency figures take primary visual hierarchy without overwhelming cognitive bandwidth. 
- **Disciplined & Restrained:** Employs deliberate white space, structural dividers, and deliberate semantic color accents to signal liquidity, alerts, and budgetary progress.

### Design Movement
The aesthetic synthesizes **Corporate / Modern** structure with **Minimalist** clarity:
- Clean light surfaces framed by low-contrast structural borders (`#E2E8F0`).
- No decorative skeuomorphism or distracting drop-shadow heavy layers; tactile elevation is achieved primarily through distinct surface tiers and ultra-subtle, slate-tinted ambient glows.
- Systematic tabular numeric alignment ensuring rapid vertical scanning across transaction feeds and financial ledgers.

## Colors

The palette leverages a high-contrast corporate foundation rooted in authoritative blues and slate neutrals, punctuated by semantic indicators specifically tuned for financial telemetry.

### Palette Architecture
- **Primary (`#2563EB`):** Royal Blue drives active interactive states, core calls to action, primary tab selections, and focused financial flows. A deeper shade (`#1E40AF`) is reserved for high-contrast interactive hovers and authoritative key figures.
- **Secondary (`#0F172A`):** Deep Slate serves as the high-contrast foundation for primary typography, card titles, key currency indicators, and dominant tabular values.
- **Tertiary / Success (`#10B981` / `#059669`):** Pure emerald green reserved strictly for positive cashflow, incoming credits, investment yield, and budget surplus indicators.
- **Neutral Stack:**
  - Base Background: `#F8FAFC` (Slate 50) creates a soft, anti-glare canvas.
  - Surface Containers: `#FFFFFF` (Pure White) defines floating card tiers and ledger backgrounds.
  - Borders & Dividers: `#E2E8F0` (Slate 200) offers crisp separation.
  - Subdued Text / Captions: `#64748B` (Slate 500) gives accessible contrast (exceeding WCAG 2.1 AA 4.5:1 against white).
  - Secondary Text: `#334155` (Slate 700) powers form labels and table column headers.

### Semantic Tones
- **Alert / Over-budget (`#DC2626` / `#EF4444`):** Flags deficits, budget breaches, high-risk merchant alerts, and critical account warnings.
- **Warning / Approaching Threshold (`#D97706` / `#F59E0B`):** Identifies categories nearing 85%+ utilization and pending transaction states.

## Typography

Typography balances geometric structure with utilitarian readability:
- **Headings & Key Metrics (`Plus Jakarta Sans`):** Selected for crisp, contemporary geometry with balanced terminal curves. Used across global account balances, budget category summaries, and high-level card titles.
- **Body, Inputs & Micro-copy (`Inter`):** Selected for neutral, industrial legibility across dense data environments.
- **Numeric & Ledger Formatting:** All table cells, transaction amounts, and balance sheets must apply the `font-variant-numeric: tabular-nums` CSS rule to prevent lateral shifting during live currency ticker updates and to guarantee vertical alignment of decimal points.
- **Currency Typography:** The Rupee sign (`₹`) is rendered inline without spacing ahead of whole numbers (e.g., `₹4,25,800.00`), using the Indian numbering format system (two-digit groupings following the initial three-digit thousand block).

## Layout & Spacing

The layout is constructed on an 8pt architectural rhythm, defaulting to a 12-column responsive fluid grid on desktop viewports and condensing into modular single-column vertical stacks on mobile screens.

### Grid & Breakpoints
- **Desktop (1280px+):** 12-column grid, `2rem` outer page margins, `1.5rem` gutters. Content maximum width is capped at `1440px` to maintain fixed horizontal gaze lines for complex analytics tables.
- **Tablet (768px - 1279px):** 8-column grid, `1.5rem` margins, `1rem` gutters. Multi-column financial summary widgets shift to a 2x2 modular matrix.
- **Mobile (Up to 767px):** 4-column grid, `1rem` canvas margins, `1rem` gutters. Data lists reflow from horizontal tables into stacked atomic transaction cards.

### Spacing Token Application
- `space-xs` (4px): Micro-gaps between inline badge icons and labels, button icon padding.
- `space-sm` (8px): Stacked gap between form labels and inputs, list item sibling spacing.
- `space-md` (16px): Internal padding for compact cards, table cell vertical padding, metric block grouping.
- `space-lg` (24px): Standard container padding for primary dashboard cards, horizontal spacing between segmented controls.
- `space-xl` (32px): Vertical gap between major layout blocks (e.g., balance overview chart to categorical ledger).

## Elevation & Depth

Visual hierarchy relies on crisp surface-container differentiation and low-contrast perimeter outlines rather than high-contrast, heavy skeuomorphic drop shadows.

### Elevation Strategy
- **Layer 0 (Canvas Base):** Rendered in `#F8FAFC`. Houses background page navigation, global sidebars, and inactive track regions.
- **Layer 1 (Card & Module Surfaces):** Rendered in `#FFFFFF`, framed with a 1px solid structural border in `#E2E8F0`. Layer 1 items use an ambient slate shadow:
  - `box-shadow: 0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.03)`
- **Layer 2 (Dropdowns, Floating Overlays, Date Pickers):** Elevated above standard modules with a clean white surface, 1px `#E2E8F0` border, and diffused depth:
  - `box-shadow: 0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.03)`
- **Layer 3 (Modals & Critical Confirmation Sheets):** Positioned over an ambient backdrop dimming layer (`rgba(15, 23, 42, 0.4)`), surrounded by a refined multi-stop shadow:
  - `box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.05)`

## Shapes

The design system enforces a roundedness level of `2`, establishing an approachable yet disciplined corporate appearance.

### Shape Distribution
- **Base Components (`rounded` / 0.5rem - 8px):** Form input fields, interactive primary buttons, dropdown triggers, and tabular action cells.
- **Medium Surfaces (`rounded-lg` / 1rem - 16px):** Nested containers, modal dialogue panels, and flyout navigation drawsheets.
- **Primary Cards (`rounded-xl` / 1.5rem - 24px):** Global financial metric cards, budget progress containers, chart analytics canvases, and ledger sections.
- **Pill Shapes (`rounded-full`):** Category chips, dynamic status pills (e.g., "Paid", "Pending", "Over-Budget"), and user avatar frames.

## Components

### Buttons
- **Primary:** Solid `#2563EB` fill, white text, bold `Inter` label. Height: `40px` (desktop), internal padding: `0 16px`. Active hover shifts to `#1E40AF`. Focused with a 2px offset ring (`#2563EB` at 40% opacity).
- **Secondary:** Surface `#FFFFFF` with a 1px solid `#CBD5E1` border, text `#0F172A`. Hover shifts surface to `#F8FAFC`.
- **Tertiary / Ghost:** Transparent background, `#334155` text. Used for secondary inline table actions (e.g., "Export CSV").

### Chips & Badges
- **Status Pills:** Height: `24px`, padding: `0 10px`, typography: `label-md`.
  - Positive (Credit): Background `#ECFDF5`, text `#065F46`, 1px border `#A7F3D0`.
  - Negative (Debit/Alert): Background `#FEF2F2`, text `#991B1B`, 1px border `#FECACA`.
  - Neutral / Category: Background `#F1F5F9`, text `#334155`, 1px border `#E2E8F0`.

### Cards & Financial Tiles
- **Standard Metric Card:** Background `#FFFFFF`, border `1px solid #E2E8F0`, corner radius `1.5rem` (`rounded-xl`), padding `1.5rem` (`space-lg`). Includes category label at the top, primary `currency-stat` display, and contextual badge indicating percentage delta against the prior month.

### Lists & Ledger Tables
- **Table Headers:** Background `#F8FAFC`, uppercase `0.75rem` bold text with `0.05em` letter-spacing, height `40px`, border-bottom `1px solid #E2E8F0`.
- **Table Rows:** White surface, height `56px`, hover state highlights row with `#F8FAFC`. Bottom divider `1px solid #F1F5F9`. Numeric columns must align strictly to the right.

### Input Fields & Controls
- **Text Inputs & Dropdowns:** Height `40px`, background `#FFFFFF`, border `1px solid #CBD5E1`, radius `0.5rem`. Focus transition produces a sharp `2px` ring in `#2563EB` without altering element geometry.
- **Checkboxes & Radios:** `18px` structural frame, radius `4px` for checkboxes and `50%` for radios. Selected state fills with `#2563EB` housing an interior white glyph.

### Budget Progress Indicators
- **Track:** Height `8px`, background `#F1F5F9`, radius `rounded-full`.
- **Fill Bar:** Dynamic width, radius `rounded-full`. Transitions from `#10B981` (under 75%) to `#F59E0B` (75%-90%) and `#EF4444` (exceeding 90%).
